# ORJİNAL DAT

Bu klasörde yalnızca resmi launcher'dan alınmış temiz
`client_local_English.dat` tutulur.

Oyun güncellemesi geldiğinde yeni temiz DAT'ı proje kökündeki `GÜNCELLEME`
klasörüne koyun; buradaki eski temiz DAT'ı silmeyin. `LOTRKaynakGonder.exe`
ile iki temiz dosyayı seçip **GitHub'a Gönder** düğmesine basın.

Çevrilmiş DAT, tam DAT veya kişisel dosya bu klasöre konulmaz ve GitHub'a
yüklenmez. Ayrıntılı sıra için [`docs/GUNCELLEME-REHBERI.md`](../docs/GUNCELLEME-REHBERI.md)
dosyasına bakın.
